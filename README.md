# AIT Exam Prep — Applied Information Technology Year 11 ATAR

Units 1 & 2 шалгалтын бэлтгэлийн статик сайт. Ойлголтыг монголоор тайлбарлаж, шалгалтын хариултыг англиар, marker-ийн хайдаг keyword-тайгаар сургана.

## Агуулга
- **32 сэдэв** (SCSA AIT ATAR Year 11 syllabus-ийн бүх content area). "Слайдаас" гэсэн тэмдэгтэй сэдвүүд нь багшийн слайдад шууд байгаа.
- **6 интерактив дүрслэл**: vector ба raster-ийг томруулах, VLOOKUP/HLOOKUP, файлын хэмжээний тооцоолуур, site map (three-click rule), LAN topology (эвдрэлийн симуляц), rule of thirds ба reading gravity.
- **Санамсаргүй дадлага**: 75 загвар хариулттай асуулт, өөрийгөө дүгнэх, сул сэдэв.
- **Практик**: 8 хэрэглээний даалгавар (формула, файлын хэмжээ, формат сонгох, site map, LAN, poster-ийн annotation, иш татах).
- **Quiz** (44), **Flashcards**, **Command words**.

## Бүтэц
```
index.html · styles.css · app.js   — хуудасны бүтэц (CS Exam Prep-ийн engine)
data.js                            — агуулга (SITE, TOPICS, VARIANTS, QUIZ, CODE_TASKS)
viz.js                             — дүрслэлүүд
PROJECT_PROMPT.md                  — Claude Project-ийн instructions
```
