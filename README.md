# AIT Exam Prep — Applied Information Technology Year 11 ATAR

A static study site for the Units 1 & 2 exam: plain-English explanations, the keywords markers look for, and model answers broken down mark by mark.

## What's inside
- **32 topics** covering every content area of the SCSA AIT ATAR Year 11 syllabus. Topics tagged "From slides" come directly from the teacher's slides.
- **6 interactives**: vector vs raster zoom, VLOOKUP/HLOOKUP, file size calculator, site map (three-click rule), LAN topologies with failure simulation, rule of thirds and reading gravity.
- **Random drill**: 75 questions with model answers, self-marking and weakest-topic tracking.
- **Practice**: 8 applied tasks (formulas, file size, format choice, site map, LAN design, poster annotation, referencing).
- **Quiz** (44 questions), **Flashcards**, **Command words**.

## Structure
```
index.html · styles.css · app.js   — page shell
data.js                            — content (SITE, TOPICS, VARIANTS, QUIZ, CODE_TASKS)
viz.js                             — interactives
PROJECT_PROMPT.md                  — Claude Project instructions
```

Course materials (`ait-exam/`) are excluded from the repo via `.gitignore`.
